# Payment is an EFT an Admin confirms

Credits are bought by EFT into the business bank account. The buyer uploads proof, and the Credits land only when an Admin confirms that payment. Rejecting it grants nothing. A card provider was rejected: the Catalog is four ZAR prices, the volume does not need a second ledger, and confirmation is the same act that already gates a Referral reward. The cost is that Credits wait on a person.
